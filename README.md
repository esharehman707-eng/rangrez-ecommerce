# Rangrez (MERN)
React + Vite + Tailwind (client) and Node + Express + MongoDB (server).

1. server: `cd server && npm install && cp .env.example .env && npm run dev`
2. client: `cd client && npm install && npm run dev`
3. Open http://localhost:5173 and login at /login (admin@shop.com / admin123, set in server/.env)
